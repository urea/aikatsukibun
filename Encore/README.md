# アイカツ！アンコール気分

通常版の `App/` をコピーした、アンコール用の独立したアプリです。

- アンコール版の公開先: https://aikatsu-encore-kibun.vercel.app/
- 通常版の公開先: https://aikatsukibun.vercel.app/

- `videos.json`: アンコール用の動画ID一覧。
- `catalog.json`: 楽曲情報の正本。動画IDごとに `title`（楽曲）、`startSeconds` / `endSeconds`（元動画内の開始・終了秒）、`mode`（モード）、`difficulty`（難易度）、`idol`（アイドル）、`result`（成績）、`author`（投稿者名）、`authorHandle`（ハンドル）を管理します。
- 「アイドル活動！」（7:15〜8:51、1分36秒）と「君のEntrance」（7:31〜9:57、2分26秒）を登録済みです。楽曲位置・モード・難易度・アイドル・成績はユーザー指定、投稿者は動画情報で確認しています。
- PCでは再生画面と選曲一覧で楽曲情報を確認できます。幅899px以下では再生画面の詳細情報を非表示にし、選曲一覧で確認できます。検索は楽曲名・モード・難易度・アイドル・成績・投稿者にも対応しています。
- 投稿者名のリンクから、その投稿者のYouTube動画一覧を新しいタブで開けます。ハンドルがある既存動画も対象です。ハンドルのない新規動画は取得元のチャンネルURLを保存します。投稿者名からURLは推測せず、URLが分からない場合は名前のみを表示します。選曲ボタンと投稿者リンクは別の操作で、リンクを押しても再生は始まりません。
- 「PR｜Amazonでアイカツ！を探す ↗」を、再生画面の「おまかせ／選ぶ／…」の上と、選曲画面の曲数表示の行に小さく表示します。Amazonのツールバーで取得した検索結果へのアソシエイトリンク（`mczd-22`）を新しいタブで開き、説明文はページ末尾に掲載します。再生画面ではリンクと操作ボタンを同じ下部エリアにまとめ、動画・3色パネルのサイズ指定は変更していません。ページ末尾までスクロールできます。
- 登録した楽曲位置で再生・再再生・シークします。進行表示は楽曲区間内の0:00〜曲の長さ。シーク後も終了位置を越えて再生しないようにします。
- 曲がない場合は「楽曲準備中」を表示し、YouTubeプレーヤーを読み込みません。
- 新規追加動画はNeonの専用テーブル `encore_shared_videos` へ保存し、全利用者で共有します。YouTube動画本体は保存しません。
- 履歴・お気に入り・設定・最終動画・曲名キャッシュ・共有一覧の表示用キャッシュは、`aikatsu_encore:` から始まるブラウザー保存キーを使います。従来のローカル追加動画も保持しますが、自動で公開しません。
- 通常版の楽曲・譜面・環境設定・保存データは引き継ぎません。

## ローカルで確認

このフォルダーで `npm.cmd ci` を実行後、`.env.local` にサーバー用 `DATABASE_URL` を設定し、プロジェクトルートで `npm.cmd run dev:encore -- --host 127.0.0.1 --port 18743 --strictPort` を実行します。確認URLは `http://127.0.0.1:18743/` です。ローカルでも同じ登録API・DBを使うため、テストは専用DBを使用してください。ポートを変更する場合は `D:\Archive\WEB_PORTS.md` と使用状況を確認してください。

ビルドはプロジェクトルートの `npm.cmd run build:encore`。公開用ファイルは `Encore/dist/` に出力されます。

## 楽曲追加と公開

1. アンコールの動画を確認し、`videos.json` に動画IDを、`catalog.json` に対応する楽曲情報を登録します。開始・終了秒は動画全体の先頭から数えます。旧形式で追加済みの、区間指定がない動画は動画全体を再生します。
2. Vercelの `aikatsu-encore-kibun` プロジェクトは、Root Directory=`Encore`、Framework=Vite、Install Command=`npm ci`、Build Command=`npm run build`、Output Directory=`dist` で公開します。GitHubの `urea/aikatsukibun` と接続し、通常版とは別のプロジェクトで管理します。
3. 各Vercelプロジェクトの環境変数 `VITE_RELATED_SITE_URL` に相手の公開URLを設定します。アンコール版では `https://aikatsukibun.vercel.app/`、通常版では `https://aikatsu-encore-kibun.vercel.app/` を使います。未設定の間はリンクを表示しません。ローカル設定の例は `.env.example` にあります。
4. `main` への更新後、両プロジェクトのデプロイ結果と公開URLを確認します。アンコール版だけにアンコールの曲が表示されること、PC／スマホ表示、楽曲区間の再生、相互リンクでの往復を確認します。

画面の「動画を追加」では、YouTube URL・楽曲名・開始／終了時刻・モード・難易度・アイドル・成績がすべて必須です。投稿者の入力は不要です。追加時にURLからチャンネル名を自動取得し、チャンネルURLに `@ハンドル` が明示されている場合はハンドルも保存します。古いキャッシュに頼らず取得し、投稿者名を取得できない場合は入力を保持して再試行を案内します。既存の投稿者情報は保持します。時刻は `7:15` または `1:07:15` の形式で、終了を開始より後にします。動画から難易度を判別できない場合は `‐` を選択します。登録済みの動画IDは重複登録せず、既存の情報を上書きしません。

楽曲名・アイドルは公式一覧の候補から選択できます。アイドルには「マイキャラ」もあります。どちらも「自由入力」を選ぶと入力欄が現れ、候補にない名称をそのまま保存できます。候補データは `registration-options.js` にまとめ、2026-10-09時点の[公式アイドル一覧](https://dcd.aikatsu.com/encore/idol/)と[公式楽曲リスト](https://dcd.aikatsu.com/encore/pdf/music-list.pdf)から登録しています。候補の更新をしなくても、自由入力で新しい名称を追加できます。

難易度は「☆１　かんたん」「☆２　ふつう」「☆３　むずかしい」「☆４　すごくむずかしい」「☆５　とてもむずかしい」の5段階と、動画から判別できない場合の「‐」から選択します。追加・編集画面、選曲一覧、PC再生画面で同じ表記を使用します。従来の保存値（`-`・名称）は維持し、既存動画も編集時に正しく選択されます。

成績は「クリア」（フルコンボせずにクリア）、「フルコンボ」（フルコンボでクリア）、「オールパーフェクト」（すべてパーフェクトでクリア）から選択します。新規登録した楽曲情報はオンラインの共有一覧へ保存され、別の端末でも区間再生と選曲一覧に反映されます。お気に入りへの追加は登録した端末だけです。旧形式のローカル追加動画も保持します。動画のシリーズ判定は自動化していないため、アンコールの動画を選んで登録してください。

「選ぶ」の各動画にある「編集」から、楽曲名・開始／終了時刻・モード・難易度・アイドル・成績を修正できます。初期登録の「アイドル活動！」「君のEntrance」も共有動画として編集できます。共有動画はログインなしで誰でも編集でき、保存後は全利用者に反映されます。YouTube URLと取得済みの投稿者は変更できません。静的カタログは通信失敗時などの初期情報として残し、共有一覧に保存された編集内容を優先します。従来のローカル追加動画はそのブラウザー内だけで編集し、共有一覧へ自動公開しません。

編集時は読込時点のrevisionを送信し、ほかの利用者が先に変更していた場合は保存を拒否して入力を残します。「最新の情報を読み直す」で入力を最新の内容に置き換え、再確認して保存できます。revisionはDBのJSON内容から算出するため、テーブルの変更は不要です。

## 共有APIの設定

- Vercelのサーバー用環境変数 `DATABASE_URL` にNeon接続URLを設定します。`VITE_` は付けません。接続情報はGitやフロントのビルドへ含めません。
- 初回のみ `server/schema.sql` を実行します。既存の通常版データには触れず、アンコール専用の動画・登録頻度テーブルを作ります。
- `GET /api/videos` は共有一覧、`POST /api/videos` は8項目の登録入力を受け取ります。投稿者情報はサーバー側で取得し、入力内容を再検証します。重複はDBの一意制約でも拒否し、既存データを上書きしません。
- `PATCH /api/videos` はフォーム入力と `id`・`revision` を受け取り、既存の共有動画だけを更新します。投稿者を保持し、DBの単一UPDATEでrevisionを照合します。入力・同一サイトからの送信・サイズ・頻度の制限は登録時と同様に適用します。
- 登録APIは匿名利用できます。JSONのサイズ制限・同一端末からの短時間の大量登録を制限します。保存する識別子はハッシュ化し、IPアドレスをそのまま保存しません。
- 一覧はアプリ起動時と選曲画面を開くたびに更新します。取得に失敗した場合は手元の一覧を表示し、再読み込みを案内します。登録失敗時は入力を保持し、成功扱いでローカル保存しません。
